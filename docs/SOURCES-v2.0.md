- Apple LocalAuthentication: https://developer.apple.com/documentation/localauthentication/lacontext
- Apple Family Controls: https://developer.apple.com/documentation/familycontrols
- Apple DeviceActivitySchedule: https://developer.apple.com/documentation/deviceactivity/deviceactivityschedule
- Apple Vision OCR: https://developer.apple.com/documentation/vision/vnrecognizetextrequest
- ZIPFoundation 0.9.20: https://github.com/weichsel/ZIPFoundation
- Anki export/legacy compatibility: https://docs.ankiweb.net/exporting.html
